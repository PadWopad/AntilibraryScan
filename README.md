# 🕵️ Лаборатория совпадений (Coincidence Laboratory)

**Лаборатория совпадений** — это спекулятивный аналитический движок, который превращает глобальные сигналы реального времени в многослойные мифологии влияния. Он использует продвинутый нарративный синтез для поиска паттернов в шуме современного мира.

## 🌟 Основные возможности

- **Нарративный движок:** Синтезирует глобальные сигналы (новости, финансы, космос, военные данные, ИИ и др.) в спекулятивные теории.
- **Нейронный граф знаний:** Интерактивный граф в стиле Obsidian для визуализации связей между сигналами и теориями.
- **Инъекция сигналов:** Ручной ввод собственных сигналов или загрузка папок (txt, md, json) для влияния на ход повествования.
- **Режим Оракула:** Просмотр подтвержденных аномалий и исторических паттернов.
- **Спекулятивный интеллект:** Работает на базе Google Gemini 3.1 Pro для глубоких рассуждений и генерации нарративов.

## 📡 Источники данных (Сигналы)

Приложение агрегирует данные из более чем 20 открытых источников для формирования «мировой картины»:

- **Технологии и ИТ:** Hacker News (Top Stories & AI Search).
- **Финансы:** CoinCap (рынок криптовалют).
- **Космос:** Spaceflight News, NASA APOD, NOAA (солнечная активность).
- **Наука:** CrossRef (новые публикации), arXiv (квантовые исследования и аномалии).
- **Безопасность:** URLHaus (вредоносные ссылки), USGS (землетрясения).
- **Мировые события:** ReliefWeb (конфликты и катастрофы), Wikipedia (события дня), Wikimedia (тренды просмотров).
- **Общество и Тренды:** Reddit (Hot topics), GitHub (тренды разработки), World Bank (демография и труд).
- **Культура и Быт:** Art Institute of Chicago, Open Library, Jikan (аниме), Aladhan (лунные циклы), Carbon Intensity (экология).
- **География:** REST Countries, Open-Meteo (погода).

## 🛠 Технологический стек

- **Фронтенд:** React 18, Vite, Tailwind CSS, Framer Motion (motion/react).
- **Бэкенд:** Express.js (полностековый режим).
- **ИИ:** Google Gemini API (@google/genai).
- **Визуализация:** react-force-graph-2d, Recharts, D3.
- **Иконки:** Lucide React.

## 🚀 Быстрый старт

### Требования

- [Node.js](https://nodejs.org/) (v18 или выше)
- [npm](https://www.npmjs.com/)
- API-ключ Google Gemini (получите его в [Google AI Studio](https://aistudio.google.com/app/apikey))

### Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/coincidence-laboratory.git
   cd coincidence-laboratory
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` в корневой директории и добавьте ваш API-ключ:
   ```env
   GEMINI_API_KEY=ваш_api_ключ_здесь
   ```

4. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```

5. **Откройте приложение:**
   Перейдите по адресу `http://localhost:3000` в вашем браузере.

## 📖 Как пользоваться

1. **Наблюдайте за лентой:** Приложение автоматически подтягивает сигналы из глобальных источников в реальном времени.
2. **Изучайте теории:** Нажмите на карточку теории, чтобы увидеть «Тезис», «Цепочку наблюдений» и «Критический анализ».
3. **Нейронный граф:** Используйте виджет графа, чтобы увидеть, как сигналы связаны с теориями. Нажмите на иконку развертывания для полноэкранного просмотра.
4. **Вводите сигналы:** Используйте боковую панель, чтобы ввести собственные наблюдения или загрузить папку с заметками.
5. **Переключайте режимы:** Переключайтесь между режимами «Вымысел» и «Аналитика» в настройках, чтобы изменить способ интерпретации данных нарративным движком.
